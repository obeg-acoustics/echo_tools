# echo_tools
Set of Matlab scripts to process EK60/80 acoustic transects and analyze acoustic data

-> filter_echogram.m : Apply multiple filters to unprocessed echograms and bin the acoustic signals at desired resolution. 

-> clean_manual.m : Manually inspect and remove non biological noises (eg false bottom, CTD, interferences)
